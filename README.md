SOC Simulator — Incident Response Training Platform — Personal project, 2026
Built a self-contained browser-based SOC simulator with SIEM, ticketing, log search, threat intelligence, messaging, evidence handling and reporting modules. 
Implemented a token-based action economy to enforce realistic triage prioritisation under time pressure, plus a structured escalation workflow and an AI-driven analyst NPC for team interaction.
Authored a full incident scenario — credential compromise via vishing-based MFA bypass, data exfiltration, host persistence, and breach notification obligations under Australia's Notifiable Data Breach scheme.
